# Plumber Today — Pipe Hopper

A playful, plumbing-themed arcade game for **Plumber Today**. Keep the plumber airborne, navigate the pipe gaps, and beat your best score.

## Play

Open `index.html` in a browser, then click, tap, or press **Space** to flap. The game works on desktop and mobile browsers and stores the best score locally.

## Run locally

No build tools are required. You can:

1. Download or clone this repository.
2. Open `index.html` in a browser.

For local development with a simple server, run `python3 -m http.server` from the project directory and visit `http://localhost:8000`.

## Customize

- Update the company link and copy in `index.html`.
- Adjust colors and layout in `style.css`.
- Tune physics, obstacles, and drawing in `game.js`.
